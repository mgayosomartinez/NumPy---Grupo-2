# Campeonato – Grupo 2

## Descripción del proyecto

Este proyecto consiste en el desarrollo de un sistema de análisis de datos de un campeonato, utilizando **Python**, **NumPy** y **Matplotlib**.

El programa permite almacenar y procesar los puntajes obtenidos por los jugadores en las distintas partidas, para luego realizar cálculos estadísticos y obtener información relevante sobre su desempeño.

## Funcionalidades

- Registro y almacenamiento de partidas y puntajes.
- Cálculo del promedio general del campeonato.
- Identificación del jugador con mejor y peor rendimiento promedio.
- Cálculo de promedios por jugador y por partida.
- Análisis de la variación de puntajes para identificar al jugador con mayor diferencia entre su resultado máximo y mínimo.
- Evaluación de la evolución del rendimiento de los jugadores.
- Visualización gráfica de los resultados.


## Estructura del proyecto

| Archivo | Descripción |
|---|---|
| `main.py` | Ejecución principal del programa. |
| `partida.py` | Gestión de la información relacionada con las partidas. |
| `repositorio.py` | Almacenamiento y acceso a los datos del proyecto. |
| `visualizar.py` | Generación y presentación de visualizaciones. |
